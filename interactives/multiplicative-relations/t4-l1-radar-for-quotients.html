Learning Intention and Success Criteria

Learning Intention

We are learning to estimate a quotient before we divide, so we can tell whether an answer is reasonable.

Success Criteria

  • I can find a multiple of the divisor that is close to the dividend.
  • I can use that multiple to estimate the quotient.
  • I can say whether a division answer is reasonable and explain why.

Q4. 624 ÷ 3 = 28 ?
Number line

Think: what number is 624 close to?
Pair: tell your partner why 28 looks wrong.

Radar estimate
624 is close to 600.
600 ÷ 3 = 200
So the answer must be about 200.
The mistake
2H
0T
8O

The student skipped the 0 in the tens place.

Correct answer
624 ÷ 3 = 208
Check
3 × 208 = 624
